# PintaPro

Aplicación web sencilla para preparar presupuestos de pintura de **Pinturas Decodl SL**.

## Publicar gratis con GitHub Pages
Sube `index.html`, `style.css` y `app.js` a la raíz del repositorio (no subas solo el ZIP).
Después entra en **Settings → Pages**, elige **Deploy from a branch**, rama **main** y carpeta **/(root)**.
